## Características

- **Expiración de Enlaces Flexible**: Elige cuánto duran tus enlaces, desde 1 día hasta siempre. Las opciones incluyen 1 día, 1 semana, 2 meses, 6 meses, 1 año o nunca.
- **Seguridad de Enlaces**: Selecciona entre "Short" (5 caracteres) para brevedad o "Safe" (7 caracteres) para URLs más difíciles de adivinar.
- **Enfoque en la Privacidad**: Código abierto y transparente.
